## Historical pre-repair diagnosis: why nine weather artifacts defeated crowding-1.3 safety

1. Query concepts for “AI code review agent” are seven tokens: `ai`, family AI, `code`, family code, `review`, family review, `agent`. “AI weather model” supplies `ai` and family AI: **2/7**, rounded **0.29**, above the default **0.18**. Generic AI/model vocabulary alone qualifies; neither software object nor reviewing operation is required. `review/audit/analysis` is also an overbroad family. Title/body overlap ignores role, negation and task relationships. [^lib/scoring/semantic-filter.ts]
2. The two-item audit floor is **not** the cause of this failure: all nine pass the threshold, not just the retained floor. A higher item count makes the count/source sufficiency cap saturate (`9/8` capped at 1, `3/3` = 1). Eight responding adapters and similar low subscores give near-perfect agreement, rounded to confidence100. The cap measures quantity after a flawed qualification decision, not semantic quality. [^lib/scoring/evidence.ts] [^lib/scoring/score.ts]
3. Fully “qualified” samples preserve raw totals. With stronger stars/dates/large totals this flaw can affect crowding as well as confidence; this exact null-meta/date fixture has score2, so the demonstrated failure is chiefly authoritative certainty of low observed supply, **not a high crowding score**. Query-aware dedup uses this same lexical relevance function; filtering improvement must align dedup selection without splicing evidence provenance. [^lib/scoring/score.ts] [^lib/core/dedup.ts]
4. Existing regressions reject plain weather widgets, retain audit floors and cap one weak observation, but do not reject *AI* weather near-misses across enough channels. The 512 synthetic combinations mostly inject already chosen relevance values or clear title matches, not independent natural-language task judgments. More combinatorial coverage cannot validate the semantic premise. [^tests/semantic-filter.test.ts] [^tests/evidence-integrity.test.ts] [^tests/crowding-attenuation.test.ts]

Other offline probes underscore why globally raising 0.18 is unsafe: “Automated PR reviewer” with an LLM/diff description also scores0.29; “AI code generator” explicitly without review scores0.61; medical chart review AI and code-of-conduct review assistant each score0.57; a task-looking title contradicted by a weather/no-code-review body scores1. A scalar threshold cannot reliably separate these relations. These are authored probes, not accuracy rates. [^lib/scoring/semantic-filter.ts]
